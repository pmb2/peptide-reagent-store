# The $100 Budget — allocation & the honest gap

## Reality check first

The Grok conversation's own lean-launch math puts cash-to-first-sale at **$3,300–6,500**,
dominated by lawyer ($400–750), LLC+publication ($550–800), pilot inventory ($900–1,800),
and lab tests ($450–1,200). **$100 cannot buy a compliant inventory-holding launch.**

What $100 CAN do (and what this project does): build every piece of software, the site,
the outreach machine, and the compliance apparatus for free, so the only cash spent is
on entity + first tested inventory when revenue or savings exist. That defers the
$3.3k+ to week 3–5 instead of day 1, and lets the first sales fund it.

## Allocation of the $100

| Line | Cost | Why |
|---|---|---|
| Domain (Namecheap/Porkbun, 1yr) | $10–12 | Own domain, not a subdomain — processors and FDA both look |
| Email on domain (Zoho Mail free tier / MXRoute trial) | $0 | No Gmail storefront |
| Hosting: GitHub Pages (this static store) | $0 | Free, reliable, SSL included |
| Storefront software: this repo (static + invoice checkout) | $0 | Built here — no Shopify/BigCommerce death risk |
| Automation: Python tools in this repo | $0 | RFQ, linter, economics, tracker |
| Email outreach: manual + this repo's generator | $0 | No paid tools; LinkedIn manual |
| Merch processor: apply ONLY to high-risk MCA (Stage 2) | $0 now | App fee typically waived; 3.5–6% later |
| **Subtotal committed** | **~$12** | |
| Reserve for pilot inventory match (held, not spent) | $50 | Conditional: released ONLY after a passing COA quote |
| Reserve for first lab test co-pay (Janoshik-style) | $38 | Conditional: released with pilot revenue |

**Rule: the $88 of conditional reserve never converts to spend until a real supplier
quote and a real test quote exist. It is a credibility line in the RFQ emails, not
burn money.**

## What stays $0 and why it works

- Static site on GitHub Pages ≈ free WooCommerce for the catalog phase; checkout is
  an invoice/quote flow (email a typed attestation form) until a processor is live.
- No ads until 20+ clean orders (conversation's own rule) — ads are Month 2+ spend,
  funded by margin, not the $100.
- LLC ($200) is deliberately NOT in the $100: it is the first use of sales revenue or
  saved cash at week 2–3. Selling research reagents pre-LLC as a sole proprietor is
  possible but counsel-flagged; the playbook sequences LLC formation before any
  inventory purchase.

## Path to profitability (carried from conversation math)

- Contribution ≈ $22/vial at $49 list / $12 landed
- Monthly fixed once live ≈ $25–40 (domain amortized, tests amortized, no other fixed)
- Breakeven ≈ **2 vials/month** on software-only overhead
  (vs 16 vials/mo carrying the full lean overhead — the $100 bootstrap's whole point)
- Target: 3 SKUs × 10 vials pilot → sell through in 3–4 weeks at 1–2 orders/day
  from lab-manager outreach → reorder 50-vial boxes of winners in Month 2.
